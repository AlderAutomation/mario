# Mario  

## Introducion  

An attempt at learning more about composition using a Mario style game. 

## Requirements

- Entities: Player, Goomba, Coin, PowerUp
- Systems: Score, Time, Start, Finish, Controls
- Mechanics: Gravity, Camera panning, platforms, pitfalls


## Technology Being Used 

Programming: C   
Rendering: Raylib   
Buildtools: CMake  
Project Management: Signboard  
Repos: Git & Gitea   

## How to Run (Until Itchio release)  

Git clone the repo and and run the startup.sh/
